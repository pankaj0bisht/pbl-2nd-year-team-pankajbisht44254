EXPLAINABLE RULE-BASED AI

Emergency vehicle allocation

Enter an emergency vehicle and its campus entry block. BFS checks connected blocks level by level and selects the nearest reachable block with free capacity.

How the AI decision works

01Read graph

Block connections are stored in a C++ adjacency matrix.

02Run BFS

Visit nearby blocks first and calculate the shortest number of edges.

03Check capacity

Ignore blocks that have no free parking slot.

04Allocate

Create the reservation and show the selected block and route.

This is a rule-based decision system using graph algorithms, not a trained machine-learning model.
